                                      Todo_list
Description:
A light-weight command-line interface (CLI) To-Do List application built in Python to help manage daily tasks efficiently. The application allows users to create, view, update, and remove tasks directly from the terminal, keeping track of work with status indicators (e.g., Pending / Completed) and persistent storage.

Key Capabilities
Add Tasks: Create new tasks with custom descriptions and optional priority levels.

View Tasks: Display all current tasks in a structured list alongside their completion status.

Mark Complete: Update task status when completed.

Delete Tasks: Remove individual or completed tasks from the list.

Data Persistence: Automatically save and load tasks from a local file (e.g., JSON or TXT) so progress isn't lost between sessions.
